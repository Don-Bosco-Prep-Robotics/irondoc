# Elastic

![Elastic](./imgs/elastic.avif)

Elastic is a dashboard for the robots. It can show essentially anything you publish to network tables.
The docs link is in resources. They explain things pretty well. 

You don't need to do anything special, just publish to SmartDashboard. You can then just get at them from elastic.
