# Slicing

Slicing is the act of converting geometry and print settings into gcode. We do this in one of two ways
1) A desktop slicer, like Bambu Studio
2) Bambuddy, where slicing happens on the web page

### Bambu Studio
I have very litte doubt you can find a video guide on this. 
#### Worth noting
1) We tend to use PETG
2) Slicing for the wrong printer should be caught, but if not could damage it
3) Infill, 95% of the time, doesn't need to be above 15%
